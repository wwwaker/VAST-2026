# 真实任务走查记录模板

状态：**尚未执行**。本文件是 3–5 人走查的记录模板，不是已完成结果；在有人实际完成之前，报告只能写“未验证”，不能引用任何完成率。

## 1. 走查规则

- 参与者：3–5 位未参与本原型开发的同学；记录专业背景与是否用过类似调查工具。
- 只给问题，不给事件 ID、点击路径或预期答案；主持人只在参与者完全卡住时提示一次，并记录提示内容。
- 每人独立完成三项任务，顺序随机；任务之间可以休息，但不互相讨论。
- 记录“是否独立完成、用时、错误结论、能否找回原始证据、是否混淆候选与事实”，不记录主观满意度作为主要结论。
- 原型验收目标：每项关键路径至少 80% 的参与者独立完成。样本很小，报告逐人结果与失败原因，不宣称统计意义上的普遍可用性。

失败原因分类（用于决定修复顺序，不用于给参与者打分）：

1. **入口**：找不到标签、子模式或按钮；
2. **口径**：把候选当事实、把外部报道当内部发言、把不同数据集的时间混排；
3. **证据定位**：能说出结论但回不到原始事件或来源字段；
4. **视觉/布局**：文字不可读、遮挡、需要横向滚动才能比较。

修复优先级：先修入口与口径，再修证据定位，最后调整视觉样式。每条修复在 §0.1 进度表中登记，并附上对应的 `ui_check.mjs` 断言或后端回归。
