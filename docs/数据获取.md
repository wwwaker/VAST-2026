# 数据获取与恢复

`data/` 目录不进版本库：合计 168 MB，其中单个文件最大 159 MB
（`data/processed/official_data/MC2/events.jsonl`），超过 GitHub 单文件 100 MB 的硬限制。
本仓库只保留代码与文档，数据按下面的路径恢复。

---

## 目录结构要求

导入脚本按固定相对路径读取，目录名不要改：

```text
data/
├── processed/                       # 本项目实际读取的规范化数据
│   ├── official_data/MC1/
│   │   ├── events.jsonl             # 912 条事件
│   │   ├── entities.json            # 13 个实体（对象，含 entities 数组）
│   │   └── README.md
│   ├── official_data/MC2/
│   │   ├── events.jsonl             # 185,147 条事件，159 MB
│   │   ├── entities.json            # 15,538 个实体 + org_edges
│   │   └── README.md
│   └── custom_dataset/
│       ├── events.jsonl             # 1,103 条事件，32 次运行
│       ├── entities.json            # 根即数组，330 个实体
│       ├── labels.json              # 32 条运行级标签
│       └── README.md
└── raw/                             # 原始压缩包与逐运行 JSONL，仅供溯源
```

---

## 官方数据（MC1 / MC2）

1. 从 VAST Challenge 2026 官方数据仓库获取 MC1、MC2 的原始数据包：
   <https://github.com/vast-challenge/2026-data>
2. 解压后的原始文件放入 `data/raw/official_data/MC1`、`.../MC2` 留存溯源。
3. 按 `data/processed/official_data/*/README.md` 的字段说明整理为 JSONL 事件表 + JSON 实体表。

`processed/` 与官方原始包的结构差异（顶层字段补齐、`relationships` 派生、`source_record_id` 回填等）
记录在 `docs/数据适配规则.md`，不是官方格式本身。

---

## 自建数据（CUSTOM）

由项目自己的多智能体工作流产生，共 32 次运行，覆盖正常、审批绕过、旧版本传播、重复交接四种场景。
`entities.json` 是数组（不是对象），`labels.json` 通过 `run_id` 关联运行、
通过 `affected_event_ids` 定位事件。字段说明见 `data/processed/custom_dataset/README.md`。

如需从零复现，需要重新跑一遍同样的工作流；本仓库不包含生成器。

## 恢复后如何确认没放错

```bash
cd backend
python -m app.ingest.cli --all
```

导入脚本会打印各数据集的事件数、实体数、参与者数与校验项，任一不符即非 0 退出。
基准值：

| 数据集 | 事件 | 实体 | 参与者 | 关系 |
| --- | ---: | ---: | ---: | ---: |
| MC1 | 912 | 13 | 1,322 | 2,709 |
| MC2 | 185,147 | 15,538 | 346,503 | 147,901 |
| CUSTOM | 1,103 | 330 | 1,782 | 0 |

## 如果确实需要把数据也纳入版本控制

三种做法，按需选一种：

| 做法 | 适用 | 代价 |
| --- | --- | --- |
| 删掉 `.gitignore` 里的 `data/` | 只在本地备份、不推远端 | 仓库约 170 MB，clone 变慢 |
| 用 Git LFS 跟踪 `*.jsonl` | 要推到 GitHub | 需安装 LFS，免费额度 1 GB 存储/月 |
| 只入库 `data/processed` 的 README 与 labels | 需要他人理解结构但不要数据 | 无法直接运行，仍需自行获取事件表 |
